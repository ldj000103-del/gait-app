걸음 분석

걸음을 재고, 결과마다 책·논문 근거를 보여 줘요
  • 걷기·러닝·슬로우 러닝의 케이던스(분당 걸음 수)와 GPS 속도
  • 옆·앞·뒤 영상으로 무릎·엉덩관절·발목 각도 (영상은 휴대폰 밖으로 안 나가요)
  • 모든 값에 정확도 등급과 출처(Perry 『Gait Analysis』, Neumann 『Kinesiology』, 학술지 논문)
의료 진단이 아니에요. 걸음이 걱정되면 전문가와 상담하세요.

안드로이드 내 휴대폰

화면이 꺼져도 측정되는 설치형 앱이에요. 버전 0.10
앱 받기 (약 6MB)
  1. 위 버튼을 누르면 파일을 내려받아요. 다 받으면 알림창(또는 내 파일 → 다운로드)에서 gait-analysis.apk를 눌러요.
  2. "출처를 알 수 없는 앱" 화면이 나오면 설정 → 이 출처 허용을 켜고 뒤로 가서 설치를 눌러요.
  3. "Play 프로텍트" 경고가 나오면 세부정보 더보기 → 무시하고 설치를 눌러요. 플레이스토어를 거치지 않은 앱이라 나오는 경고예요.
  4. 앱을 열고 동의 화면에서 시작해요. 측정할 때 위치·알림 권한을 허용하면 GPS 속도와 "측정 중" 알림이 동작해요.
새 버전이 나오면 같은 버튼으로 받아 위에 설치하면 돼요. 기록은 그대로 남아요.

아이폰은 설치형 앱 대신 웹앱으로 써요. 기능은 같아요(측정 중엔 화면을 끄지 말고 주머니에 넣어요).
지금 카톡 안에서 열려 있어요.
카톡 안의 화면에서는 "홈 화면에 추가"가 안 돼요. 아래 버튼을 누르거나, 화면 구석의 메뉴(⋯ 또는 공유 아이콘)에서 "Safari로 열기"를 눌러 주세요.
